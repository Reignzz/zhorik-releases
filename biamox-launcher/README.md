# Biamox Launcher — рабочий телефон в стиле iOS (Moto G57)

Лаунчер-«оболочка» для Android: заменяет рабочий стол Moto на стиль iOS и собирает весь офис Biamox в одном месте.

| Что есть | Как это работает |
|---|---|
| 🏠 Рабочий стол в стиле iOS | 3 экрана: «Сегодня» (виджеты), главный (иконки), библиотека приложений. Стеклянный док, поиск, скруглённые иконки, лёгкая вибрация на нажатия |
| ✳️ Claude | Чат с Claude Opus 5.5; видит статистику, задачи, почты, команду и соцсети компании; пишет письма, посты, идеи роликов |
| 🎙️ «Привет, Биамокс» | Голосовые команды как «Привет, Siri»: «открой офис», «какая выручка», «добавь задачу…», «позвони…», «напиши письмо…», «открой наш инстаграм», «пункт управления». Остальное отвечает Claude голосом |
| 📊 Статистика | KPI, графики, источники; берётся с вашего сервера (JSON), пока его нет — демо |
| 🎬 Студия роликов | Ваша веб-студия внутри лаунчера (загрузка видео, камера, микрофон) + быстрые действия |
| 🏢 Офис | Задачи, почты, команда (звонок/письмо), соцсети, быстрые ссылки |
| ✉️ Почта | Ящики компании вшиты; чтение писем по IMAP, ответы, черновики от Claude |
| 🌐 Соцсети | Instagram, TikTok, YouTube, Facebook, Telegram, LinkedIn — виджет и голосом |
| 📞 Разделы телефона | Телефон, Сообщения (SMS), Контакты, Фото, Часы, Календарь, Калькулятор, Браузер, Карты, Файлы — единые iOS-иконки |
| 🎛 Пункт управления | Фонарик, яркость, громкость, Wi-Fi, Bluetooth, «Не беспокоить», поворот, авиарежим |
| 🔒 Заставка | Фирменная заставка BIAMOX на экране блокировки (или ваша картинка) |
| 🎵 Звуки | Свои мягкие звуки в стиле iOS: рингтон, уведомление, сообщение, будильник |
| 🧹 Очистка | Удаление рекламных и мешающих приложений Moto/Facebook/Amazon и т.д. (возвращается одной командой) |
| ⬇️ Обновления | Лаунчер обновляется сам из релиза GitHub |

## Установка с Mac (≈10 минут)

1. **На телефоне** включите отладку по USB:
   Настройки → О телефоне → 7 раз нажмите «Номер сборки» → Настройки → Система → Для разработчиков → **Отладка по USB**.
2. **На Mac** скачайте эту папку (или весь репозиторий) и подготовьте ключи:
   ```bash
   cd biamox-launcher/scripts/mac
   cp secrets.example.json secrets.json
   open -e secrets.json      # вставьте ключ Claude, пароли почт, адрес студии, ссылки на соцсети
   ```
3. Подключите телефон кабелем и запустите:
   ```bash
   bash install.sh
   ```
   На телефоне нажмите «Разрешить отладку» (галочка «Всегда»). Дальше скрипт всё сделает сам:
   **бэкап телефона → установка → разрешения → Biamox по умолчанию → ключи и почты → заставка и звуки → очистка рекламы → ускорение.**

> Root **не нужен** и не рекомендуется: разблокировка загрузчика Motorola стирает телефон, отключает Google Pay/банки и гарантию. Всё сделано через ADB.

## Бэкап и откат

- `install.sh` **всегда** сначала делает полный бэкап в `~/BiamoxBackup/<дата>/`:
  список приложений и их состояние, APK ваших приложений, все системные настройки, приложения по умолчанию,
  фото/видео/документы/загрузки/медиа мессенджеров, контакты/SMS/звонки (если Android разрешит).
- Вернуть телефон как было: `bash scripts/restore_full.sh` (флаг `--push-media` вернёт и файлы).
- Вернуть только удалённые приложения: `bash scripts/restore.sh`.
- Дополнительно сделайте копию Google: Настройки → Система → Резервное копирование → «Создать копию».

## Что заполнить (secrets.json)

| Поле | Где взять |
|---|---|
| `claudeApiKey` | console.anthropic.com → API Keys |
| `mailPasswords` | Gmail: myaccount.google.com → Безопасность → **Пароли приложений** (16 букв) |
| `studioUrl` | адрес вашей студии роликов |
| `statsUrl` / `statsToken` | адрес JSON со статистикой (формат — в `app/src/main/java/com/biamox/launcher/core/Stats.kt`) |
| `config.socials` | **точные ссылки на соцсети Biamox** (сейчас стоят шаблоны `…/biamox`) |
| `config.mailboxes`, `config.team` | реальные адреса почт и телефоны сотрудников |

Секреты хранятся на телефоне **зашифрованно** (Android Keystore), файл после импорта удаляется, в git не попадает.

## Сборка

APK собирается автоматически в GitHub Actions (`.github/workflows/biamox-launcher.yml`) и выкладывается в релиз
`biamox-launcher` (релизы Жорика не затрагиваются). Локально: Android Studio → открыть папку `biamox-launcher`.

**Безопасная подпись (рекомендуется):** создайте свой ключ и добавьте секреты репозитория
`BIAMOX_KEYSTORE_B64` (base64 файла .jks), `BIAMOX_KEYSTORE_PASSWORD`, `BIAMOX_KEY_ALIAS`, `BIAMOX_KEY_PASSWORD`.
Без них используется тестовый ключ из репозитория — он публичный.

## Ограничения Android (честно)

- Системные экраны Moto (шторка уведомлений, настройки системы, экран звонка) без root остаются Android-овскими; стиль iOS — во всём, что внутри лаунчера.
- Звуки iOS принадлежат Apple — вместо них свои звуки в похожем стиле.
- «Привет, Биамокс» работает при включённом экране (на выключенном Android не даёт слушать микрофон сторонним приложениям без большого расхода батареи).
