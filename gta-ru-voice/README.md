# Русская озвучка GTA 6 (PS5) через MacBook Air M4

Звук игры идёт с карты захвата на Mac. Mac распознаёт английскую речь, переводит её
и озвучивает на русском в наушники. Задержка 1–3 секунды. Голос синтезированный, но всё работает без взлома консоли.

## 1. Что нужно

- **USB-карта захвата с HDMI-выходом (passthrough / loop-out)**, например Elgato HD60 X или любая дешёвая
  «USB 3.0 capture card с loop out». Через выход картинка идёт на телевизор без задержки.
- Наушники для Mac. Проводные или USB лучше AirPods: у Bluetooth своя задержка.

Подключение:
```
PS5 HDMI → HDMI IN карты захвата
           HDMI OUT карты → телевизор (играешь как обычно)
           USB карты → MacBook
```

## 2. Настройки PS5

- **Настройки → Система → HDMI → «Включить HDCP» → выключить.** Без этого карта захвата
  получит пустой сигнал. Netflix и другие приложения с защищённым видео при этом не работают, после игры можно включить обратно.
- В настройках звука игры убавь **громкость диалогов** (если там есть такой ползунок), чтобы английский был тише русского.
  Если отдельного ползунка нет, можно оставить английский на ТВ потише и слушать русский в наушниках.

## 3. Русский голос на Mac

Системные настройки → Универсальный доступ → Устный контент → Системный голос → **Управлять голосами** →
Русский → скачай **Milena (улучшенный)** или **Yuri**. Улучшенные версии звучат заметно лучше.

## 4. Установка (один раз)

В Терминале:
```bash
# если нет Homebrew: https://brew.sh
brew install python@3.12
cd ~/Downloads/gta-ru-voice          # папка, куда положил файлы
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 5. Запуск

```bash
source .venv/bin/activate
python gta_ru_voice.py --list        # найди название карты захвата и наушников
python gta_ru_voice.py --input "USB" --output "Наушники"
```
- `--input` и `--output` принимают часть названия устройства из `--list`.
- В первый раз macOS спросит доступ к микрофону для Терминала, разреши.
  Звук с карты захвата считается микрофоном.
- В первый раз скачается модель распознавания (~1.5 ГБ).
- В терминале видно английскую фразу и перевод.

## Тонкая настройка

| Параметр | Что делает |
|---|---|
| `--voice Yuri` | мужской голос вместо Milena |
| `--rate 240` | говорить быстрее (по умолчанию 210) |
| `--vad 2` | ловить больше речи, но чаще реагировать на музыку (по умолчанию 3) |
| `--silence-ms 400` | быстрее заканчивать фразу, задержка меньше, но фразы рвутся |
| `--model mlx-community/whisper-small-mlx` | лёгкая модель: быстрее, но хуже распознаёт |

## Ограничения

- Под громкую музыку, стрельбу и радио в машине распознавание ошибается. В тихих катсценах работает лучше всего.
- Перевод через Google Translate, нужен интернет.
- Все персонажи говорят одним голосом.
- Если накопилась очередь фраз, старые пропускаются, а голос ускоряется, чтобы не отставать.
